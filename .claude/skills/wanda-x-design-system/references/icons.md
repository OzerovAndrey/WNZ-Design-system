# Іконки

## Правило
**Усі іконки в Wanda X ДС замінюються на найближчі відповідники з бібліотеки `Static — Icons`.** Це стосується:
- векторних іконок, намальованих прямо в компоненті (VECTOR / BOOLEAN_OPERATION / згруповані вектори);
- detached іконок;
- інстансів з інших іконкових бібліотек: `BR / Default / …`, `icons / general / …`, `icons / …`, `icon / status / …`, `menu / …`, голі `close`, `cancel`, `chevron-down`, `plus`, `flame`, `goblet` тощо.

## Як замінювати
1. Знайти іконку за змістом: `search_design_system` (entity `component`, query — назва/сенс) або перелік компонентів сторінки `3. Separation`.
2. Outline за замовчуванням; `-filled` — для активних/вибраних станів, якщо оригінал був заповнений.
3. Вставляти **інстансом** з бібліотеки, у слот з swap-властивістю `↳ 💠 …`; розмір — через токен `{component}/icon-size/{size}`, колір — через токен fill/text компонента.
4. Немає точного відповідника → взяти найближчий за сенсом і записати пару «стара → нова» в беклог; якщо відповідника немає зовсім — позначити `needs icon` і не малювати власний вектор.
5. Після заміни в компоненті — перевірити, що всі варіанти отримали однакову іконку і preferred values у swap-властивості вказують на `Static — Icons`.

## Відомі нюанси бібліотеки
- Вектори іконок мають власну (сіру) заливку: після swap у компоненті колір треба прив'язувати заново (див. `rebuild-workflow.md` → Пастки).
- Регістр назв непослідовний (`Barbell`, `Darts` поруч з lowercase) — шукати без урахування регістру.
