# Перескладання компонента — робочий процес

Відпрацьовано на `Anchor` (2026-10-19). Застосовувати до кожного компонента, що чиститься.

## 0. Принципи
- **Точна копія, нічого не додумувати.** Ті самі розміри, кількість елементів, стани, вигляд. Без нових брейкпоінтів, фейдерів, станів, слотів — якщо команда не попросила.
- **Виняток — `Inverted`.** Інвертована версія обов'язкова для всіх компонентів: якщо в оригіналі її немає — додаємо `Inverted = False | True` (`naming.md` → Inverted).
- **Правильна збірка** — змінюється тільки *як* зібрано: токени, інстанси, неймінг, властивості.
- **Поруч з оригіналом.** Оригінал не чіпаємо, нова Section праворуч.
- **Документація — у скілі**, не в Figma.

## 1. Перевірити доступ
Перед будь-якою зміною — пробний запис (створити й видалити прямокутник). Помилка `Can't call ... in read-only mode` = акаунт Figma-конектора має лише перегляд → попросити **Can edit** на файл для акаунта конектора (або перепідключити конектор). Не імпровізувати обхідні шляхи.

## 2. Розібрати оригінал (read-only)
Дамп дерева: типи, auto layout, розміри, `boundVariables` (з назвами змінних, позначати remote), text styles, override-и в інстансах, звідки іконки.
Типові знахідки:
- чужі (remote) змінні замість власних;
- override розміру/кольору в інстансах іншого компонента (`Navigation/Item` з висотою 20 замість 32, колір лейблу токеном кнопки);
- кешований колір в інстансі, що не збігається з його ж токеном (оригінал «темний», а токен дає світлий) — копія йде за токенами, розбіжність фіксуємо;
- іконки не зі `Static — Icons`.

## 3. Токени компонента (Token Studio)
- **Свої компонентні токени**, а не прив'язка напряму до semantic/core: `<component>.*` (розміри/падінги/gap), `border-radius.<component>.*`, `contextual.<component>.*` (кольори).
- Значення — **аліаси**: розміри — на `spacing.*` / `layout.*` / `border-radius.core.*`; **кольори — тільки `semantic.*`** (ніколи `core.*`).
- Брендова різниця: якщо semantic дає різний результат у MB і XON — значення в `mb/component` і `xon/component` можуть різнитись (напр. темний текст: MB `semantic.text.default.heading`, XON `semantic.text.static.primary`).
- Структура «в рядок», без рівня з одним листком (`token-studio.md`).
- Для кожної кольорової частини — пара `<part>` і `<part>-invert` (`contextual.anchor.item.*` / `contextual.anchor.item-invert.*`). Розмірні токени спільні.
- Обидва сети: `mb/component` і `xon/component` (відрізняються лише там, де відрізняється бренд, напр. радіус).
- Формат і як додавати — `token-studio.md`.

## 4. Змінні в Figma
У колекції `Product` змінні з **тими самими назвами** (`/` замість `.`), аліаси, **явні scopes** (не `ALL_SCOPES`): GAP — падінги/gap, WIDTH_HEIGHT — розміри, CORNER_RADIUS, FRAME_FILL/SHAPE_FILL, TEXT_FILL. Експорт з Token Studio потім оновлює їх за назвою, прив'язки не злітають.

## 5. Збірка
- Під-компонент (`Anchor/Item`) — власний, з власними токенами; не перевикористовувати чужий компонент з override-ами.
- Батьківський (`Anchor`) — інстанси під-компонента.
- Іконки — імпорт зі `Static — Icons`, шар `Icon`, розмір і колір — токенами.
- Text — text style + колір токеном.
- `resize()` скидає sizing у FIXED → після нього знову ставити `primaryAxisSizingMode = 'AUTO'` (HUG). Перевіряти розміри проти оригіналу.

## 6. Прив'язка — токени напряму
На кожну властивість: **токен Token Studio** (`setSharedPluginData('tokens', key, JSON.stringify(name))`) **+** однойменна змінна. Inspect у Token Studio має показувати токени без ⬡ і без значка обірваного зв'язку. Обірваний зв'язок = токена немає в активних сетах → дописати токен, не перепривʼязувати.

## 7. Властивості
- Під-компонент: `↳ 💠 Icon` (swap), `✏️ Label` (text). Не додавати перемикачів, яких команда не просила (лейбл у Anchor вимикати не можна).
- Батьківський: вкладені інстанси — **exposed**; видимість кожного — Boolean `Item #1…#N`, шар — та сама назва.
- Шари: `Icon` → `Label` у візуальному порядку; після swap іконки перейменувати шар назад у `Icon`.

## 8. Section
За `section-layout.md`: сіра заливка `#BBBBBB` + обведення чорне 10%, радіус 2; 80 px до країв і між компонентами, стовпчиком, під-компоненти зверху, розмір по вмісту, без превʼю й нотаток, `description` порожній.

## 9. Документація і репо
- `references/components/<component>.md` — анатомія з node ID, властивості, таблиця токенів MB/XON, рішення й відкриті питання.
- `tokens/<component>.mb.component.json`, `tokens/<component>.xon.component.json` у корені репо.
- Рядок компонента в `audit-*.md` → новий статус.

## 9a. Перевірка в обох темах
Тимчасова превʼю-рамка: інстанси всіх варіантів (`Inverted=False` і `Inverted=True`) на `semantic.background.page` і `semantic.background.slate-2` у режимах MB і XON → скріншот → видалити рамку. Звичайна версія має читатись на світлому фоні, інвертована — на темному.

## 10. Передача
Перелік відкритих питань (контраст, вибір іконки) — команді, не вирішувати самостійно. Статус Ready for dev ставить команда.

## Пастки (перевірено на Anchor)
- **Видалені змінні.** Якщо Export з Token Studio видалив/не створив змінні, шари лишаються прив'язаними до видалених і показують старий кешований колір. Перевірка: `boundVariables` → id немає в `collection.variableIds`. Лікування: створити змінні з тими самими назвами і перепривʼязати.
- **Swap іконки скидає колір.** Іконки `Static — Icons` мають власну заливку; після swap (і після `resetOverrides`) вектор стає сірим. Після кожного swap — заново прив'язати fill вектора до `contextual.<component>.<part>.icon` (змінна + токен на шарі).
- **Прихований інстанс іконки не має дітей у Plugin API.** У шарі з `visible = false` (`⬅️ Icon` за замовчуванням вимкнена) `findAll` повертає порожньо — колір і токен на вектор не ставляться. Тимчасово `visible = true` → прив'язати fill вектора → `visible = false` (перевірено на Chip/Tag).
- **Заливка, якої немає.** Прозорий стан (`core.content.a0`) не токенізуємо — шар без fill; токен `fill` лише для станів, де заливка видима (Chip `Selected`, Tag `Hover`).
- **`boundVariables` на шарах інстансу показує лише override-и.** Порожньо = успадковано від мейна, це не помилка.
- **Перевірка в обох темах:** тимчасово `setExplicitVariableModeForCollection` на Section → скріншот → повернути як було.
