# Definition of Done — коли компонент можна позначити Ready for dev

Пройти **усі** пункти. Один ❌ = не Ready.

## Структура
- [ ] Компонент лежить у Section з його назвою, на своїй сторінці і оформлена за `section-layout.md`.
- [ ] На сторінці немає сміття: нотаток, загублених інстансів, векторів, старих копій.
- [ ] Один набір на сутність — немає дублікатів з іншою назвою на цій чи іншій сторінці.
- [ ] Набір без помилок (`componentPropertyDefinitions` читається без "existing errors").
- [ ] Не продуктовий: не прив'язаний до конкретної фічі (Cashbox, Hall of fame …).

## Неймінг (`naming.md`)
- [ ] Назва набору — Title Case, без опечаток і маркерів (`[M]`, `[new]`, `(Cashbox)`).
- [ ] Ключі властивостей Title Case; значення за стандартом; немає `Property 1`.
- [ ] 0 шарів з дефолтною назвою.

## Layout
- [ ] Auto layout на всіх контейнерах з 2+ дітьми.
- [ ] Absolute — лише для оверлеїв/бейджів/масок.
- [ ] Ресайз перевірено: текст переноситься, нічого не обрізається.

## Токени (`tokens.md`)
- [ ] 0 hardcoded fill/stroke (крім масок).
- [ ] 0 текстів без text style.
- [ ] 0 effects без effect style.
- [ ] Radius, height, padding, gap, icon size — прив'язані до токенів.
- [ ] Використані лише свої contextual/semantic токени; 0 `core/*` поза тінями/градієнтами.
- [ ] 0 змінних з чужих бібліотек.
- [ ] Токени Token Studio стоять на шарах **напряму** (Inspect без ⬡ «via variable»), а не лише Figma-змінні.
- [ ] Перевірено в обох режимах — `MB` і `XON`, обидві версії — `Inverted=False` і `Inverted=True`.

## Властивості
- [ ] Іконки — `⬅️ Icon` / `Icon ➡️` + swap `↳ 💠 …`; текст — Text property.
- [ ] Стани покривають мінімум `Default | Hover | Active/Selected | Disabled` (для інтерактивних).
- [ ] Є `Inverted = False | True` для кожного поєднання варіантів; інвертовані кольори — токени `contextual.<component>.<part>-invert.*` (`naming.md` → Inverted).
- [ ] Вкладені елементи — інстанси інших компонентів ДС, не detached копії.
- [ ] Список однакових пунктів — у SLOT `Items`; фіксовані вкладені елементи — exposed + Boolean `Item #N`.

## Документація
- [ ] `description` компонента в Figma **порожній**; на канвасі немає нотаток.
- [ ] Є файл `references/components/<component>.md` (анатомія, властивості, токени, рішення).
- [ ] Посилання на компонент у коді (Code Connect) — коли з'явиться.
