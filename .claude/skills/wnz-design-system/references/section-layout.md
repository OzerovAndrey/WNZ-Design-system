# Оформлення Section на сторінці компонента

- Одна Section на компонент, назва = назва компонента (`Anchor`, `Badge`).
- Стиль Section — як у еталонів: білий фон, тонке обведення (чорний 10%), без назви-заголовка всередині.
- Всередині тільки main-компоненти / набори. Ні нотаток, ні тестових інстансів, ні превʼю-фреймів.
- Розкладка — стовпчиком:
  - **80 px** від країв Section до вмісту (зверху, знизу, зліва, справа);
  - **80 px** між компонентами по вертикалі;
  - під-компоненти (`Anchor/Item`) — вище за батьківський (`Anchor`).
- Розмір Section — по вмісту: `80 + max(width) + 80` × `80 + Σheight + 80·(n−1) + 80`.
- Section стоїть поруч з оригіналом, поки старий компонент не переведено в `Deprecated`.
